# 데이터 처리와 누수 점검

## 1. 점검 범위

검증 대상은 Window 90일, 디노테퓨란 CatBoost 95열 Optuna trial 3입니다. 기존 분할과 94열 입력을 재사용하고, 11.13 목록의 고유 방제 대상명 수로 산출한 품목별 병해충 위험 지수 1열을 결합했습니다. 아래에서는 학습·평가 자료의 분리, 결합 입력의 정렬, 예측 시점의 원천자료 가용성을 각각 다룹니다. [날짜 정의와 분할](../03_학습검증평가데이터_분할정보/README.md)

누수 점검은 어떤 값이 모델 적합에 쓰였는지, 정답이 입력에 섞였는지, 예측 시점에 해당 입력을 얻을 수 있었는지 확인하는 작업입니다. 이 실험은 학습 전처리와 검증 모델 선정을 고정해 기존 테스트에 적용했습니다. 원천 관측값의 실제 공표·수집 시각은 별도 근거가 필요한 항목으로 기록합니다.

## 2. 중복·결측·이상치 처리

| 항목 | 적용 기준 |
| --- | --- |
| 분할과 중복 | 기존 복합 검사키의 분할 간 중복 점검을 거친 동결 분할을 사용. H=1~60의 동일 검체 반복은 예측거리마다 평가하는 구조이므로 유지. 서로 다른 키로 등록된 동일 실물의 재식별은 추가 원천 점검 대상 |
| 정답 분리 | 디노테퓨란 검출 라벨은 학습·평가 정답으로 사용하고 95개 모델 입력과 분리. H가 달라져도 검사 결과는 동일한 라벨 사용 |
| 결측값과 범주 | 기상·토양의 기존 학습 기준 보완값, 범주 사전, 연도 변환을 학습 이후 고정. 원자료 결측비율 또는 결측 플래그를 함께 사용 |
| 이상치 | 기존 입력 생성에서 음수 강수량을 유효값에서 제외하고 VPD 계산에서 기온 순서와 습도 범위 확인. 토양·기상 파생 입력은 기존 보완·계산 규칙을 그대로 적용 |
| 추가 품목 입력 | 11.13 목록을 품목군×세부품목에 연결해 중복 대상명을 제거하고, 연결된 대상명 기록이 없으면 0. 고정된 품목 집계이며 검체별 검사량·검출 라벨은 집계에 사용하지 않음 |

기존 분할에서 복합 검사키는 검사 식별자·위해 라벨 이름·자료 경로의 조합입니다. 95열 실험은 이 분할의 검체와 행 위치를 대조한 다음, 품목군·세부품목 코드 쌍을 lookup과 다대일로 연결했습니다. 품목 목록에서 하나의 코드 쌍이 한 행인지 확인했고, 결합 전후 검체 수와 순서가 같고 모든 검체에 값이 연결되는지 검사했습니다. 품목별 병해충 위험 지수는 같은 검체의 60개 H 행에 동일하게 복제합니다.

기상·동적 토양의 90일 결측비율은 학습 기준 보완값을 채우기 전에 계산합니다. 예를 들어 원자료 90일 중 9일이 비어 있으면 결측비율은 `9/90 = 0.10`입니다. 모델에는 보완 후 요약값과 이 결측비율을 함께 전달합니다. 소실속도상수도 보완된 일별 토양온도로 계산하며, 60일 창에 원자료 결측이 하루라도 있으면 `missing_soil_ktemp_q10_60d`가 1입니다. [입력 정의와 계산 기간](../03_학습검증평가데이터_분할정보/README.md)

95열 모델이 재사용한 동결 94열 입력에서 토양 파생변수별 결측 플래그가 1인 행을 집계했습니다.

| 분할 | 전체 검체×H 평가쌍 | 수분 변화 7일 | 온도·수분 복합 60일 | 소실속도상수 60일 |
| --- | ---: | ---: | ---: | ---: |
| 학습 | 7,792,080 | 2,850,308 | 3,192,181 | 185,940 |
| 검증 | 2,055,360 | 669,413 | 706,594 | 118,080 |
| 테스트 | 2,650,500 | 950,450 | 994,355 | 239,580 |

예를 들어 테스트의 소실속도상수에서 239,580쌍은 전체 테스트 평가쌍의 9.04%입니다. 이는 원래 토양온도 창에 결측이 있었던 행의 수입니다. 보완된 소실속도상수와 원자료 결측 플래그는 별개의 열에 들어가며, 같은 행에서 여러 파생변수의 플래그가 1일 수 있습니다.

## 3. 입력 시점과 실제 가용성

| 입력 | 과거 실험에서 사용한 시간 범위·버전 | 별도 점검에 필요한 근거 |
| --- | --- | --- |
| 기상 8종, 동적 토양 2종 | `D−89~D`의 관측 요약과 결측비율 | D 당일 값의 실제 취득 시간과 지연 기간 |
| 강수량 누적, 평균 VPD | `D−29~D`, `D−6~D` | 일별 관측의 공개·수집 시간 및 보완 규칙 |
| 수분 변화, 온도·수분 복합지수, 소실속도상수 | 수분은 `D−14~D−1`, 복합지수·소실속도상수는 `D−60~D−1` | 전일 이후의 자료 취득 지연 및 사후 개정 이력. 기존 토양 일자료에는 사후 통합본 활용 이력이 있음 |
| 토양 pH·유기물 | 기존 지역 정적 대리지표 | 원천 조사일·공표일, 자료 연도, 관측 깊이와 단위 |
| 자료 구분, 지역, 품목, 달력, 예측거리 | 검체 분류와 D·H로 구성 | 예측 요청 시점에서 쓸 지역 및 품목 분류, 적용 사전 확인 |
| 품목별 병해충 위험 지수 | 11.13 목록의 동일 버전을 학습·검증·테스트에 후향 적용 | 과거 D의 등록·공표 자료 및 수정 이력에 따른 해당 목록의 실제 유효성 확인 |

관측일이 D까지라는 조건과 자료가 D 당시 확보됐다는 조건을 각각 확인해야 합니다. 특히 11.13 목록은 이전 기간 검체에도 공통 적용됐으므로 성능은 해당 스냅샷을 사용한 후향 비교로 해석합니다. 예측 기준일의 공표 시각과 과거 목록 버전의 가용성은 별도 확인이 필요합니다.

예를 들어 D가 2026-05-31이고 그날의 토양 일자료가 06-02에 처음 제공됐다면 관측일 조건은 맞지만 D 시점의 가용 조건은 충족하지 못합니다. 정적 토양 자료와 방제 목록에도 같은 원칙을 적용합니다. 원천을 대조할 때 관측일·조사일, 최초 공표·수집 시각, 적용 버전과 개정 시각을 표기하면 당시 사용할 수 있었던 자료를 확인할 수 있습니다.

## 4. 95열 실험에서 확인한 항목

| 점검 | 결과 |
| --- | --- |
| 검체 연결·정렬 | 학습 129,868건, 검증 34,256건, 테스트 44,175건 전부 기존 검체에 연결. 기준일, 라벨, 범주 코드, H 순서 일치 |
| 추가 입력 값 분포 | 품목별 병해충 위험 지수가 1 이상인 검체는 학습 106,617건, 검증 28,911건, 테스트 38,231건. 이 건수는 각 분할 내 양의 집계값을 가진 검체 수 |
| 저장 모델 재추론 | 저장한 CatBoost 모델을 다시 불러 검증 점수를 대조한 최대 절대 오차는 `0.0`, 고정 임계값의 판정도 일치 |
| 기준 조건의 평가 정합성 | 기존 94열 테스트의 H별 혼동행렬 건수와 해당 실험에서 재계산한 결과 일치 |
| 검증→테스트 순서 | 검증에서 trial 3 및 하나의 임계값을 선택하고 기존 테스트 전체 H에 고정 적용 |

| 분할 | 검체 수 | 지수 1 이상 | 해당 분할 내 비율 | 지수 0 | 코드 중 하나 이상이 비어 있던 검체 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 학습 | 129,868 | 106,617 | 82.10% | 23,251 | 311 |
| 검증 | 34,256 | 28,911 | 84.40% | 5,345 | 28 |
| 테스트 | 44,175 | 38,231 | 86.54% | 5,944 | 29 |

위 비율은 `품목별 병해충 위험 지수가 1 이상인 검체 ÷ 해당 분할의 검체 수`입니다. 예를 들어 테스트의 86.54%는 `38,231 ÷ 44,175`입니다. 결합 성공 건수는 모든 분할에서 전체 검체 수와 일치했습니다. 지수 0과 품목코드 공란은 각각 따로 센 수치입니다. 검체별 실제 방제 또는 등록 유효기간을 확인하는 데는 원천자료가 필요합니다.

선정 단계가 끝난 뒤 모델 파일과 설정의 해시를 고정했습니다. 이어 테스트 입력과 정답 배열을 불러와 검체×H 순서를 확인하고 95열 확률을 계산했습니다. 종료 전에 저장한 모델과 설정의 해시를 다시 확인하고, 기존 94열의 H별 `TP/FN/FP/TN/N`이 저장 성능표와 일치하는지 대조했습니다. 저장해 둔 95열 모델을 다시 불러 계산한 검증 확률은 원래 저장 확률과 최대 절대차가 0.0이었습니다. [모델·임계값과 실험 기록](../02_학습모델파일/README.md)

패키지의 공개 집계로 검증·테스트의 H별 혼동행렬과 전체 H 합산을 대조할 수 있습니다. 확률 원장까지 확인하려면 기존 동결 입력, 라벨, 저장 모델에 접근할 수 있는 환경이 필요합니다. 테스트 기간의 다른 실험 사용 이력과 별도 미사용 자료의 확보 상태는 07에서 확인할 수 있습니다. [독립평가 자료 현황](../07_독립평가데이터_현황/README.md) · [실행과 재현 범위](../04_실행환경_실행방법/README.md)

## 5. 점검 재현 순서

1. 공개 저장소 루트에서 `.\검증_실행.ps1 -ReportDir "점검/공개검산"`을 실행합니다. 파일 해시와 검증·테스트의 분모, H별·합산 혼동행렬을 대조해 남긴 JSON에서 `passed`, `summary_rows`, `horizon_rows`를 확인합니다.
2. 동결 모델을 사용할 수 있으면 같은 명령에 `-Model`과 실제 모델 경로를 지정합니다. 모델 SHA-256과 입출력 구조를 확인한 뒤 합성 3행의 확률과 판정을 대조합니다.
3. 실제 검체의 행별 대조에는 승인된 원천키·라벨·동결 입력을 사용합니다. 세 분할의 키 교집합과 검체당 H 60개, `D = M − H` 및 동일 라벨 반복을 확인하고 기존 H별 혼동행렬과 비교합니다. 원천 자료의 공표·수집 시각과 목록 버전은 별도로 대조합니다.
