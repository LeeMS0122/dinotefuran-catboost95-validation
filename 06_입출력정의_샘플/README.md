# 06. 입출력 정의·샘플

검증 대상은 디노테퓨란 CatBoost 95열 · 검증 Optuna trial 3 · Window 90일 버전입니다.

## 1. 예측 단위와 날짜

과거 평가에서는 검체×예측거리 H를 한 행으로 구성했습니다. 검사일 M과 H가 정해지면 기준일은 `D = M - H`입니다. 기준일 D를 고정한 예제에서는 대상일을 `M = D + H`로 정합니다. H는 1~60일이고 모델 입력 `horizon_scaled`는 `(H - 1) / 59`입니다.

검증 당시의 입력을 재현하려면 D에 맞는 기상·토양 요약과 파생변수를 조립하고 학습에서 정한 범주 사전, 결측 대체, 연도 표준화 규칙을 적용합니다. 방제 대상명 수에는 11.13 목록의 품목군×세부품목별 고유 명칭 집계를 사용합니다.

## 2. 입력 CSV

| 항목 | 규칙 |
| --- | --- |
| 파일 형식 | 헤더가 있는 UTF-8 CSV. BOM 유무 모두 읽을 수 있음 |
| 필수 피처 | [모델 설정](../02_학습모델파일/model_settings.json)의 `feature_order`에 기록한 95개 이름을 헤더에 포함. 스크립트가 이 순서대로 모델에 전달 |
| 범주형 4열 | `source_route`, `region`, `product_group`, `product_detail`. 모델 위치는 0부터 세어 56~59. 각 값을 학습 당시와 같은 사전의 음이 아닌 정수 코드로 입력 |
| 수치형 91열 | 동결 전처리를 적용한 유한 수치. 결측 대체값과 해당 결측 표시 열도 모델 설정에 맞게 입력 |
| 선택 메타데이터 | 검체 ID, 지역·품목명, D, M, H 등. 결과에서 행을 식별하는 데 사용하며 입력 순서와 값이 유지됨 |

같은 헤더 이름을 중복해서 쓰거나 결과 열 이름 `probability`, `threshold`, `prediction`을 입력으로 넣으면 오류로 처리합니다. CSV에는 예측에 바로 사용할 수 있도록 조립한 95개 피처가 들어 있어야 합니다.

## 3. 출력 CSV

출력은 UTF-8 BOM CSV입니다. 입력의 행 순서와 열 순서, 식별값과 앞자리가 0인 코드 표기를 보존하고 아래 세 열을 오른쪽에 추가합니다.

| 추가 열 | 의미 |
| --- | --- |
| `probability` | CatBoost가 계산한 검출 확률을 `float32`로 변환한 값. 범위는 0~1 |
| `threshold` | 검증에서 선택한 동결 임계값 `0.0583612434566021` |
| `prediction` | `probability >= threshold`이면 검출 예측 `1`, 미만이면 불검출 예측 `0` |

실제 검사 결과가 있는 과거 평가에서는 검체 ID와 H로 라벨을 연결해 판정과 대조합니다. 공개 합성 예제의 3행은 입출력 확인용으로 실제 검사 결과를 갖지 않습니다.

## 4. 합성 입력과 기대 출력

[합성 입력 CSV](prepared_features_example.csv)는 기준일과 기상·토양·품목 입력을 고정한 상태에서 H를 1, 30, 60으로 바꾼 3행입니다. [기대 출력 CSV](example_output.csv)는 동결 모델로 이 입력을 실행한 결과를 담고 있습니다.

| H | 검출 확률 | 동결 임계값 | 예측값 |
| ---: | ---: | ---: | --- |
| 1 | 0.13407738506793976 | 0.0583612434566021 | 1 (검출 예측) |
| 30 | 0.13407738506793976 | 0.0583612434566021 | 1 (검출 예측) |
| 60 | 0.13407738506793976 | 0.0583612434566021 | 1 (검출 예측) |

동결 모델의 트리에는 `horizon_scaled`로 직접 분기하는 경우가 없어 날짜와 나머지 모델 입력을 고정하면 세 행의 확률이 같게 나옵니다. 과거 성능 평가에서는 M을 고정하고 H마다 D를 다시 계산해 기상·토양·달력 입력을 조립했습니다.
