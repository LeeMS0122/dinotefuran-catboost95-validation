## 2. 배포 파일 목록과 SHA-256

[파일목록_SHA256.csv](파일목록_SHA256.csv)에서 공개 패키지에 포함된 파일의 경로, 바이트 수, SHA-256을 확인할 수 있습니다. 경로의 기준은 저장소 루트입니다.

| 열 | 의미 |
| --- | --- |
| `file` | 저장소 루트 기준 상대 경로 |
| `bytes` | 배포본 파일의 바이트 수 |
| `sha256` | 배포본 파일 바이트의 SHA-256 |

목록 파일 자체는 자기 해시를 포함하지 않습니다. 텍스트 파일은 LF 줄바꿈 기준으로 목록을 생성합니다. 체크아웃 뒤 파일을 다른 줄바꿈이나 인코딩으로 다시 저장하면 동일한 내용이어도 바이트 수나 SHA-256이 달라질 수 있습니다. 실행 후 생성한 사용자 로컬 점검 파일과 별도로 제공받는 모델은 목록 범위 밖에 있습니다.
