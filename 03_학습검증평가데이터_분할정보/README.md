# 학습·검증·평가 데이터 분할과 입력 생성

- 검증 대상 모델은 2026-11-16 검증에서 선정한 디노테퓨란 CatBoost 95열 Optuna trial 3입니다. Window는 90일, 예측거리는 H=1~60입니다.
- 공개 표에는 기간·건수와 95열의 이름·순서를 담았습니다. 검체별 기록, 라벨, 가공 입력 배열의 접근 범위는 07에 정리했습니다. [접근 범위와 독립평가 현황](../07_독립평가데이터_현황/README.md)

## 1. 검체와 정답

국내·수입 디노테퓨란 검사기록의 기존 분할에 기상·토양 입력을 연결했습니다. 검체별 `target`은 디노테퓨란 검출이면 1, 불검출이면 0이며 같은 검체의 H=1~60 행에 동일하게 사용합니다. 95열 실험은 기존 94열 실험의 검체와 분할을 재사용하고, 품목군×세부품목으로 연결한 품목별 병해충 위험 지수를 입력에 추가했습니다.

입력 배열은 검체의 분할과 순서를 고정한 뒤 만듭니다. 먼저 국내·수입 경로에 따라 지역과 품목 분류를 연결합니다. 이어 각 검체의 H마다 D를 계산하여 기상·토양 자료의 참조 구간을 잡고, 학습에서 정한 결측 보완값과 범주 사전을 적용합니다. 마지막으로 기존 94열 뒤에 품목별 병해충 위험 지수를 한 열로 붙입니다. 정답 라벨은 별도로 보관하고, 입력 행과 같은 순서로 반복합니다.

## 2. 시간 분할과 평가 분모

| 분할 | 동결 분할의 기준일 범위 | 전체 검체 | 검출 | 불검출 | 검체×H 평가쌍 | 역할 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| 학습 `train` | 2015-03-02~2024-05-01 | 129,868 | 11,505 | 118,363 | 7,792,080 | 전처리 기준 확보, 모델 적합 |
| 검증 `validation` | 2024-07-01~2025-05-01 | 34,256 | 1,406 | 32,850 | 2,055,360 | Optuna 후보 및 판정 임계값 선택 |
| 테스트 `test` | 2025-07-01~2026-06-30 | 44,175 | 1,255 | 42,920 | 2,650,500 | 선택한 모델과 임계값으로 기존 기간 후향 평가 |
| 합계 | | 208,299 | 14,166 | 194,133 | 12,497,940 | |

기간은 동결 분할 파일에 저장된 검체 기준일의 최솟값과 최댓값입니다. 테스트에서는 이 기준일이 실제 검사일 M입니다. 학습·검증은 당시 분할 파일에 저장된 날짜 기준입니다. 위 기간 사이 공백의 검사 건수는 집계 범위에서 제외됩니다. [분할 요약 CSV](분할_요약.csv)

분할마다 검체당 H=1~60을 한 번씩 계산합니다. 예를 들어 테스트 전체 H는 검체 44,175건과 60개 예측거리의 곱인 평가쌍 2,650,500개를 합산합니다. H=60은 검체당 한 번이며, H=42~55는 14개 H별 비율의 산술평균과 혼동행렬 건수의 합계로 표시합니다. [성능 집계와 비교](../05_성능검증_상세자료/README.md)

| 분할 | 검체 기준 검출 비율 | 전체 H 검출 평가쌍 | 전체 H 불검출 평가쌍 |
| --- | ---: | ---: | ---: |
| 학습 | 8.86% | 690,300 | 7,101,780 |
| 검증 | 4.10% | 84,360 | 1,971,000 |
| 테스트 | 2.84% | 75,300 | 2,575,200 |

검출 비율은 검출 검체 수 ÷ 전체 검체 수입니다. 전체 H에서 양성과 음성을 각각 60번 반영하므로 분할 내 검출 비율은 같습니다. 검증과 테스트의 검출 비율은 다르므로 Precision이나 PR-AUC를 비교할 때는 분할과 분모를 함께 확인합니다.

| CSV 열 | 읽는 방법 |
| --- | --- |
| `split` | 학습 `train`, 검증 `validation`, 기존 테스트 `test` |
| `date_start`, `date_end` | 검체 기준일의 처음과 마지막 날. 두 날짜 사이의 매일에 검사자료가 있다는 의미는 아님 |
| `specimens`, `positive_specimens`, `negative_specimens` | 검체 수, 검출 수, 불검출 수. 검출 수와 불검출 수의 합이 검체 수와 일치 |
| `evaluation_pairs` | 검체 수 × 60. 모델 하나의 전체 H 행 수 |

## 3. 검사일 M, 예측 기준일 D, 예측거리 H

검체 기준일을 M, 예측거리를 H일, 예측에 쓰는 기준일을 D로 두고 `D = M − H`로 계산했습니다. 같은 검체에서 H가 달라지면 D와 입력 관측 창도 달라집니다. 아래 두 행은 날짜 계산을 보이는 예시입니다.

| M | H | D | 기상·동적 토양 90일 창 |
| --- | ---: | --- | --- |
| 2026-06-30 | 30 | 2026-05-31 | 2026-03-03~2026-05-31 |
| 2026-06-30 | 60 | 2026-05-01 | 2026-02-01~2026-05-01 |

H=30 예시에서 D가 2026-05-31이면 강수 합은 05-02~05-31, 평균 VPD는 05-25~05-31을 사용합니다. 토양수분 변화량은 05-24~05-30의 평균에서 05-17~05-23의 평균을 뺍니다. 토양 온도·수분 복합지수와 소실속도상수는 04-01~05-30의 일별 값을 요약합니다. 모델의 `horizon_scaled`는 H=1에서 0, H=30에서 `29/59`, H=60에서 1입니다.

## 4. 95열 입력의 구성

| 입력 묶음 | 열 위치(1부터) | 열 수 | 계산·연결 기준 |
| --- | --- | ---: | --- |
| 기상 | 1~56 | 56 | 기온 3종, 상대습도, 강수, 일사량, 풍속 2종의 `D−89~D` 요약값과 원자료 결측비율 |
| 자료 구분·지역·품목, 달력·예측거리 | 57~66 | 10 | 자료 경로, 지역, 품목군, 세부품목의 범주 4열. D의 월·연중일을 각각 sin·cos로 표현하고 연도에 학습 기준의 중심·척도를 적용. H를 `(H−1)/59`로 변환 |
| 토양 | 67~84 | 18 | 토양수분·온도의 `D−89~D` 요약값과 결측비율 14열, 기존 지역 대리지표인 pH·유기물 값과 결측 표시 4열 |
| 기존 기상 파생 | 85~88 | 4 | 강수량 누적 `D−29~D`, 수증기압포차(VPD) 평균 `D−6~D`와 각 결측 표시 |
| 토양 파생 | 89~94 | 6 | 토양수분 변화량 7일, 토양온도·수분 복합지수 60일, 온도별 토양 내 디노테퓨란 소실속도상수 60일과 각 결측 표시 |
| 품목별 병해충 위험 지수 | 95 | 1 | 11.13 목록에서 품목군×세부품목별로 중복을 제거한 고유 방제 대상명 수 |

동적 기상·토양 요약값은 평균, 모표준편차, 최솟값, 최댓값, D의 값, 90일 동안의 일별 선형 기울기입니다. 결측비율은 대체 전의 결측 일수를 창 길이로 나눈 값입니다. [95열 입력 정의 CSV](입력정의_95열.csv)

토양수분 변화량은 `D−7~D−1`의 평균에서 `D−14~D−8`의 평균을 뺍니다. 온도·수분 복합지수는 `D−60~D−1`의 일별 토양온도×토양수분을 평균합니다. 소실속도상수는 같은 60일 동안 토양온도 T를 `k(T)=0.06796×2.07^((T−20)/10)`에 대입해 일별 추정치를 구하고 평균합니다. 토양온도 결측은 기존 학습 기준으로 보완한 뒤 계산합니다.

품목별 병해충 위험 지수는 같은 품목군×세부품목 안에서 고유 방제 대상명을 한 번씩 센 값입니다. 목록에 해당 기록이 없으면 0을 넣었으며, 같은 품목 조합에는 동일한 값이 들어갑니다. 이 지수는 목록에 수록된 품목별 방제 대상의 범위를 나타내는 대리 지표입니다. 개별 검체의 해충 발생이나 농약 사용은 별도 기록으로 확인합니다. 11.13 목록을 세 분할에 공통 적용했으므로 과거 예측 기준일별 가용성은 08에서 다룹니다. [전처리와 가용성 점검](../08_데이터처리_누수점검/README.md)

변수 묶음별로 전달하는 정보는 다음과 같습니다.

| 변수 묶음 | 이 입력을 쓰는 이유 | 해석 예시 |
| --- | --- | --- |
| 기상과 동적 토양의 90일 요약 | 여러 날의 수준과 변동, 최근 값, 증가·감소 방향을 함께 반영 | `soil_temperature__mean`과 `soil_temperature__slope`는 각각 토양온도의 평균과 일별 변화 방향 |
| 지역·품목·달력 | 검사 경로와 대상 분류의 차이 및 기준일의 계절성을 함께 반영 | 월과 연중일은 각 날짜의 주기적 위치를 사인·코사인 쌍으로 표현 |
| 정적 토양 | 동적 토양의 날짜별 변화와 함께 지역의 토양 배경 특성을 제공 | `soil_ph`는 기존 지역 대리지표이며 시료가 나온 개별 포장의 실측 pH와 구분 |
| 강수 누적·평균 VPD | 90일 요약과 함께 더 짧은 창의 총 강수량과 대기의 건조 정도를 반영 | `precip_sum_30`은 mm, `vpd_mean_7`은 kPa |
| 세 토양 파생값 | 절대 수분 수준, 수분 변화 방향, 같은 날의 온도·수분 조합, 토양온도에 따른 소실속도 변화를 각각 표현 | 수분 변화량이 양수이면 최근 7일 평균 수분이 앞선 7일보다 높았음 |
| 품목별 병해충 위험 지수 | 같은 품목 조합에 공통인 방제 대상 목록의 정보를 한 열로 표현 | 188개 조합 중 25개가 양의 값을 가졌으며, 나머지 163개는 집계값 0 |

방제 대상명을 셀 때는 이름의 유니코드 표기와 공백을 정리하고, 품목 조합 안에서 중복 이름을 제거했습니다. 목록의 종자소독 및 별도로 지정한 병해명 9개도 집계에서 제외했습니다. 남은 이름 수는 검체의 품목군·세부품목 **코드 쌍**에 연결했습니다. 개발 점검에서 곡류×벼는 14, 과일류×인과류는 23, 곡류×보리는 0이었습니다. 한 검체에서 H가 바뀌어도 95번째 열은 동일합니다.

## 5. 학습에서 고정한 전처리와 행 정렬

- 기존 학습 자료에서 정한 결측 보완값, 연도 변환 기준, 범주 사전을 검증과 테스트에도 적용했습니다. CatBoost는 이 방식으로 조립한 수치값을 사용하고, 범주 4열의 기존 정수 코드는 문자열 표현으로 받습니다.
- 입력과 정답은 검체 순서에서 H 오름차순으로 대조했습니다. 검체의 위치가 `i`일 때, H행의 0부터 센 위치는 `i×60 + H−1`입니다. 95열 실험의 정렬 기록에서 208,299검체의 기준일·라벨·범주 코드 및 H 순서가 기존 분할과 일치했습니다.
- 공개 예제는 조립된 95열 CSV를 사용합니다. 예제를 실행할 때는 공개 입력 정의와 열 이름·순서를 대조할 수 있습니다. [입출력 정의와 예제](../06_입출력정의_샘플/README.md)

검체 위치가 0부터 세어 5번이라면 전체 행 300~359가 그 검체의 H=1~60입니다. 예측값을 원래 검체로 묶어 검산할 때는 행 수에 더해 이 순서와 라벨 반복을 대조합니다. 공개 검증은 합성 3행으로 이 입력 계약을 확인합니다. 실제 검사자료의 행별 대조에는 승인된 동결 입력과 라벨이 필요합니다.
