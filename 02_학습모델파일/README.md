# 02. 학습모델파일

검증 대상은 디노테퓨란 CatBoost 95열 · 검증 Optuna trial 3 · Window 90일 버전입니다. 검증에서 선택한 모델과 임계값을 동결해 과거 테스트 기간의 검체에 적용했습니다.

## 1. 모델 버전과 파일

| 항목 | 내용 |
| --- | --- |
| 모델과 예측 대상 | CatBoost 이진분류, 식품 검체의 디노테퓨란 검출 여부 |
| 학습 입력 | 95열, Window 90일, seed 42 |
| 추가한 입력 | `dinotefuran_pest_target_name_count`. 11.13 목록에서 품목군×세부품목별 고유 방제 대상명 수를 집계 |
| 모델 선정 | 검증 Optuna trial 3 |
| 저장된 트리 | 138개 |
| 모델 파일 형식 | CatBoost 네이티브 `.cbm` |
| 모델 파일 SHA-256 | `1606487d29220860e20edbe9d60ecdc9d4559f8d9f1c88b4486a9c31ea7ee8ca` |

[모델 설정](model_settings.json)에 95개 피처 이름과 순서, 범주형 피처 위치, 학습 설정, 선정 지표와 임계값을 기록했습니다. 공개 패키지에는 이 설정 파일이 포함됩니다. 추론에 필요한 동결 `model.cbm`은 승인된 경로로 받아 로컬에 저장한 뒤 실행 명령에 지정합니다. 실험과 동일한 모델인지 SHA-256으로 확인합니다.

## 2. 검증 선정 기준과 검출 판정

15개 trial 중 8개를 완료했고 7개를 가지치기했습니다. 검증 전체 H=1~60에서 기상 8종 비교 모델의 검증 Precision에서 2%p를 뺀 `0.12127633716066934`를 하한으로 적용했습니다. 이 하한을 충족하는 범위에서 Recall이 가장 높았던 trial 3을 선택했습니다. 동률일 때는 Precision이 높은 후보를 우선했습니다.

| 항목 | 저장 값 |
| --- | ---: |
| 검증 Precision | `0.12128153218691112` |
| 검증 Recall | `0.9238975817923186` |
| 검증 선정 임계값 | `0.0583612434566021` |

모델이 산출한 검출 확률이 `0.0583612434566021` 이상이면 검출 예측 `1`, 미만이면 불검출 예측 `0`입니다. 과거 테스트 비교의 모든 H에 같은 모델과 임계값을 적용했습니다.

[`optuna_trials.csv`](optuna_trials.csv)에는 15개 trial의 상태, 탐색 파라미터, 가능한 경우의 검증 Precision·Recall·임계값 및 저장 트리 수가 들어 있습니다. Trial 0은 95열 미튜닝 모델의 저장 점수를 사용한 기준 trial입니다. Trial 3은 최대 400회 반복 설정에서 선택된 138개 트리를 저장했습니다.

## 3. 모델로 확인하는 항목

추론 스크립트는 `model.cbm`의 해시를 확인한 뒤 모델을 불러와 피처 이름과 순서, 범주형 위치, 트리 수, 클래스 순서를 대조합니다. [실행방법](../04_실행환경_실행방법/README.md)에 따라 모델 경로를 지정하면 합성 입력 3행으로 확률과 판정을 확인할 수 있습니다.
