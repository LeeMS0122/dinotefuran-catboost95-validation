# 독립평가 데이터 현황과 기존 자료 사용 이력

## 1. 평가 대상과 자료 확보 상태

| 항목 | 현재 상태 | 근거·범위 |
| --- | --- | --- |
| 기존 테스트 재현 및 비교 | 수행 | 2025-07-01~2026-06-30에 검사한 44,175건. 검출 1,255건, 불검출 42,920건. 검체×H 평가쌍 2,650,500개 |
| 학습·입력 선정·모델 선택·튜닝에 사용 이력이 없는 별도 평가자료 | 미확보 | 이번 패키지에서 이전 실험과의 중복 및 사용 이력을 확인해 독립평가용으로 확정한 코호트가 없음 |
| 별도 코호트에서의 평가 | 미시행 | 평가자료와 당시 가용한 입력을 확보한 뒤 동결 모델로 평가 |
| 평가자료 확보 예정일 | 미정 | 승인된 원천 접근, 결과 확정, 기존 실험 사용 이력 및 예측 시점 입력의 가용성 확인 필요 |

공개 성능은 기상·토양·파생 입력과 11.13 방제 대상명 수를 적용한 95열 모델의 기존 기간 후향 결과입니다. 독립평가 성과는 미측정 상태입니다. [데이터 분할과 입력 정의](../03_학습검증평가데이터_분할정보/README.md) · [공개 성능표](../05_성능검증_상세자료/README.md)

## 2. 단계별 데이터 사용

| 단계 | 학습 | 검증 | 기존 테스트 |
| --- | --- | --- | --- |
| 95열 모델 적합 | 학습 기준으로 입력 보완과 변환, CatBoost 적합 | 고정 전처리의 검증 입력으로 후보 점수 확인 | 저장 모델과 고정 전처리 적용 |
| 95열 Optuna와 임계값 | 학습 자료로 후보 적합 | Precision 하한을 충족하는 후보 중 Recall이 가장 높은 설정 및 임계값 선택 | 검증에서 선택한 trial 3과 임계값 `0.0583612434566021`을 모든 H에 공통 적용 |
| 다른 개발 실험 | 각 실험의 학습 조건 사용 | 각 실험의 검증 조건 사용 | 같은 검사기간의 테스트 정답을 Optuna 목적함수 및 임계값 선택에 활용한 별도 이력이 있음 |

95열 trial 3의 선정 기록에서 테스트 사용 항목 `test_used_for_model_or_threshold_selection`은 `false`입니다. 이 항목은 해당 실행의 선정 절차를 설명합니다. 같은 기간이 실험 전체에서 이미 활용됐으므로 이 패키지에서는 결과를 기존 평가 재현 및 비교로 표기합니다. [저장 모델 설정과 선정 기준](../02_학습모델파일/README.md)

## 3. 별도 평가자료 확정과 원천 접근

| 확인 항목 | 필요한 자료·기록 |
| --- | --- |
| 검사 범위 | 평가 대상 기간, 국내·수입 범위, 검사 확정일과 라벨 확정 방식, 전체·검출·불검출 건수 |
| 기존 자료와 중복 | 원천 검사키로 학습·검증·기존 테스트와의 교집합 확인. 기간이 새로워도 다른 실험의 사용 이력은 별도로 점검 |
| 기존 실험 사용 이력 | 후보 기간과 검체가 변수 발굴, 모델 선택, 임계값 조정에 사용됐는지 실행 기록과 대조 |
| 당시 입력의 가용성 | D 이전·당일 관측의 최초 수집·공표 시간, 수정본의 반영 시점, 범주·토양·기상 자료의 적용 버전, 방제 대상 목록의 시점별 유효성 |
| 재현 대상 고정 | 모델 파일, 입력 순서, 전처리 사전, 임계값과 해시를 실행 전 확인. 사전에 정한 평가 범위·집계 방식으로 점수 산출 |

원천 검사자료와 검체별 결합 배열을 대조하려면 자료 담당 부서가 승인한 환경과 접근 권한이 필요합니다. 원천 기록에서는 검사일·확정 라벨·품목·지역·자료 구분, 입력 원천에서는 관측·공표 시각 및 사용 버전을 확인합니다. 공개본에는 승인된 집계 결과와 재현 절차를 담습니다. [실행 환경과 재현 방법](../04_실행환경_실행방법/README.md)
